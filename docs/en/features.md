# Features

HPXPANEL keeps the familiar panel workflow and adds operator-grade pieces that actually change how you run a fleet.

## Headline additions

<div class="callout-new">

**L2TP/IPsec & IKEv2** — native VPN in the same user/core pipeline. Stock OS clients. Shared IPsec credentials. Dedicated core editors.

</div>

<div class="callout-new">

**IP Limiter** — cap concurrent unique client IPs per user. Abuse control without sitting on every session.

</div>

<div class="callout-new">

**Command-deck UI** — cobalt accents, pixel borders, multi-step create-user wizard, subscription usage gauge + traffic chart.

</div>

## Full surface

| Area | Capabilities |
| --- | --- |
| Control plane | Web UI, REST API, multi-node, multi-admin RBAC, CLI, Telegram |
| Proxy stack | VMess, VLESS, Trojan, Shadowsocks, WireGuard, Hysteria2 |
| Native VPN | **L2TP/IPsec**, **IKEv2/IPsec** |
| Security | TLS, REALITY, HWID limits, IP Limiter |
| Delivery | Subscriptions (V2Ray / Clash / ClashMeta), QR, usage page |
| Ops | Traffic / expiry / periodic reset, core editors, statistics |
