# Введение

# HPXPANEL

**Консоль управления прокси в стиле command deck.**

В центре — **[Xray-core](https://github.com/XTLS/Xray-core)**: VMess, VLESS, Trojan, Shadowsocks, TLS и REALITY. Рядом — **WireGuard**, **Hysteria2** и при необходимости **IPsec (IKEv2 / L2TP)**.

## Почему HPXPANEL?

- **Сила Xray** — VLESS / VMess / Trojan / Shadowsocks с TLS и REALITY
- **Современные туннели** — WireGuard и Hysteria2
- **Нативный VPN** — L2TP/IPsec и IKEv2 для встроенных клиентов ОС
- **Ops UI**, IP Limiter, HWID, подписки, REST API, Telegram, CLI, RBAC

## Быстрый старт

1. [Установка](/ru/installation)
2. Temp-key для owner
3. Дашборд → owner

5. При необходимости IPsec — [L2TP и IKEv2](/ru/protocols/ipsec)
