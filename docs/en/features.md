# Features

HPXPANEL keeps a full proxy-ops surface — Xray at the core, modern tunnels beside it, native VPN when the client demands it.

## Headline capabilities

<div class="callout-new">

**Xray-core stack** — VMess, VLESS, Trojan, Shadowsocks with TLS & REALITY. Multi-inbound, multi-protocol users, editable cores. This is the daily driver for most fleets.

</div>

<div class="callout-new">

**WireGuard & Hysteria2** — fast modern tunnels when you need a different performance / transport profile next to Xray.

</div>

<div class="callout-new">

**L2TP/IPsec & IKEv2** — native OS VPN in the same user/core pipeline. Stock clients. Shared IPsec credentials.

</div>

<div class="callout-new">

**IP Limiter + command-deck UI** — concurrent IP caps, multi-step user wizard, subscription usage gauge + traffic chart.

</div>

## Full surface

| Area | Capabilities |
| --- | --- |
| Control plane | Web UI, REST API, multi-node, multi-admin RBAC, CLI, Telegram |
| **Xray stack** | VMess, VLESS, Trojan, Shadowsocks, TLS, REALITY, core editors |
| Modern tunnels | WireGuard, Hysteria2 |
| Native VPN | L2TP/IPsec, IKEv2/IPsec |
| Security | HWID limits, IP Limiter |
| Delivery | Subscriptions (V2Ray / Clash / ClashMeta), QR, usage page |
| Ops | Traffic / expiry / periodic reset, statistics |
