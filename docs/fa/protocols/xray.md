# استک Xray

<div class="callout-new">

**قلب HPXPANEL، Xray-core است.** بیشتر ناوگان اینجا زندگی می‌کند — پروتکل‌های انعطاف‌پذیر، REALITY / TLS، چند inbound، و سابسکریپشنی که همه کلاینت‌ها بلدن.

</div>

## پروتکل‌ها

### VLESS
سبک و مدرن؛ جفت ایده‌آل با **REALITY** و TLS برای شبکه‌های سخت.

### VMess
کلاسیک Xray با اکوسیستم کلاینت خیلی بزرگ — هنوز workhorse سازگاری.

### Trojan
ظاهر شبیه HTTPS؛ برای ترافیکی که باید داخل جلسات TLS-مانند قاطی شود.

### Shadowsocks
ساده و همه‌جا حاضر؛ first-class در پنل، نه آپشن درجه دو.

## امنیت و ترانزپورت

| لایه | نقش |
| --- | --- |
| **TLS** | رمزنگاری استاندارد |
| **REALITY** | استتار / ضد‌تشخیص قوی‌تر |
| Multi-inbound | چند لیسنر / fallback روی پورت‌های هوشمند |
| Multi-protocol | یک اکانت، چند پروتکل Xray |

## جریان کار اپراتور

1. ساخت/ویرایش **کور Xray**
2. اتصال host / inbound
3. فعال‌سازی پروتکل روی یوزر (مرحله Access ویزارد)
4. ارسال **سابسکریپشن** — V2Ray / Clash / ClashMeta
5. مانیتور مصرف در صفحه ساب + آمار پنل

می‌توانی کنارش WireGuard / Hysteria2 یا L2TP / IKEv2 هم بدهی — و با **IP Limiter** قفل سوءاستفاده کنی.
