# کاربران و محدودیت‌ها

## ویزارد ساخت یوزر

1. **هویت**
2. **دسترسی** — پروتکل / پروکسی / گروه
3. **محدودیت** — ترافیک، انقضا، ریست، **IP Limiter**، HWID
4. **پیشرفته**

## IP Limiter

سقف تعداد **IP یکتای همزمان** برای هر یوزر — کنترل سوءاستفاده بدون قطع کامل استفادهٔ چنددستگاهی مشروع.

## چند پروتکل

یک یوزر می‌تواند همزمان پروکسی و کرِدِنشیال IPsec برای L2TP / IKEv2 داشته باشد.
