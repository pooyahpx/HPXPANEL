# Обзор протоколов

## Семейство Xray

| Протокол | Зачем |
| --- | --- |
| **VLESS** | лёгкий, гибкий, отлично с REALITY / TLS |
| **VMess** | классика, огромная экосистема клиентов |
| **Trojan** | трафик похож на HTTPS |
| **Shadowsocks** | простой и вездесущий |
