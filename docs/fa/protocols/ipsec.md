# L2TP و IKEv2 / IPsec

<div class="callout-new">

یکی از بلندترین آپگریدهای HPXPANEL: **IPsec واقعی** داخل همان جریان پنل — نه وصلهٔ جدا.

</div>

## مقایسه سریع

| | L2TP/IPsec | IKEv2/IPsec |
| --- | --- | --- |
| حس | کلاسیک و آشنا | مدرن و موبایل‌پسند |
| پورت | `500` / `4500` / `1701` | `500` / `4500` |
| کلاینت | پروفایل VPN داخلی OS | نیتیو روی پلتفرم‌های اصلی |

هر دو یک **یوزرنیم/پسورد مشترک IPsec** دارند.

## کی L2TP؟

وقتی یوزر نمی‌خواهد (یا نمی‌تواند) کلاینت Xray بگذارد و فقط «VPN سیستم» می‌خواهد.

## کی IKEv2؟

شبکه موبایل با قطع‌وصل زیاد، ریکانکت بهتر، ستاپ‌های گواهی‌محورتر.

## جریان کار اپراتور

1. کورهای IPsec را در UI کور پیکربندی کن
2. پروتکل را مثل بقیه به یوزر/گروه بده
3. جزئیات اتصال + کرِدِنشیال را تحویل بده
4. در صورت نیاز سابسکریپشن پروکسی را هم نگه دار

با **IP Limiter** برای اکانت‌های لو‌رفته جفتش کن.
