# نمای کلی پروتکل‌ها

HPXPANEL **اول Xray** است؛ بعد تانل‌های مدرن و VPN نیتیو.

## خانواده Xray (استک اصلی)

| پروتکل | چرا محبوب است |
| --- | --- |
| **VLESS** | سبک، انعطاف‌پذیر، عالی با REALITY / TLS |
| **VMess** | کلاسیک، اکوسیستم کلاینت عظیم |
| **Trojan** | ترافیک شبیه HTTPS |
| **Shadowsocks** | ساده، امتحان‌پسند، پشتیبانی گسترده |

لایه‌ها: TLS · **REALITY** · چند inbound / چند پروتکل روی یک یوزر

→ [استک Xray](/fa/protocols/xray)

## تانل‌های مدرن

**WireGuard** — سریع و تمیز · **Hysteria2** — عملکرد قوی روی مسیرهای بد

## VPN نیتیو

L2TP/IPsec · IKEv2/IPsec → [راهنما](/fa/protocols/ipsec)

## چی انتخاب کنم؟

| نیاز | انتخاب |
| --- | --- |
| مقاومت در برابر سانسور، REALITY، کلاینت‌های متنوع | **Xray** |
| سرعت ساده و مدرن | **WireGuard** |
| شبکه ضعیف / UDP-محور | **Hysteria2** |
| VPN خودِ سیستم‌عامل | **L2TP / IKEv2** |
