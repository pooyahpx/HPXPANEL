# Subscriptions

## Client formats

Subscription links work with common clients:

- V2Ray family
- Clash / ClashMeta

## User delivery page

The HPXPANEL subscription page is built as a mini command deck:

- usage **gauge**
- metrics rail
- traffic **chart**
- protocol links
- QR + copy actions
- theme toggle

Users see remaining quota and how they are connecting — without asking you for screenshots.

## Operator tips

- Keep subscription URLs HTTPS in production
- Pair with IP Limiter / HWID when accounts leak into public channels
- For IPsec users, remember L2TP/IKEv2 use connection details + shared credentials — not an Xray-style URL alone
