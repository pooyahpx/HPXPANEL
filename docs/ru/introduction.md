# Введение

# HPXPANEL

**Консоль управления прокси в стиле command deck** — панель для пользователей, нод, ядер и подписок.

HPXPANEL для операторов с реальным флотом: сотни аккаунтов, несколько нод, разные ядра и клиенты, которым нужен **нативный VPN ОС**. Стек: **Python / FastAPI**, **React**, **Xray-core**, **WireGuard**, **IPsec (IKEv2 / L2TP)**.

## Почему HPXPANEL?

- **Нативный VPN** — L2TP/IPsec и IKEv2 в том же user/core workflow
- **Острый ops UI** — cobalt command-deck, pixel-рамки
- **Контроль абьюза** — IP Limiter и HWID
- **Понятная доставка** — страница подписки с gauge и графиком
- **Автоматизация** — REST API, Telegram, CLI, RBAC
